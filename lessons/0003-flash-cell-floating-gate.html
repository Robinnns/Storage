Flash 存储单元：靠"困住电荷"存储

浮栅晶体管 · 阈值电压 · 三个操作 · NAND vs NOR

🎯 为什么学这课

你的岗位是 NAND Flash 系统集成。这课补齐存储单元三部曲的最后一环：SRAM（6T）、DRAM（1T1C）、Flash（浮栅晶体管）。学完你能从第一性原理解释：为什么 Flash 断电不丢数据？为什么写之前必须擦除？为什么 NAND 能到 ~4F² 而 SRAM 要 ~120F²？
实践衔接：你阶段 5 要驱动的板载 IS25L128F 就是 NOR Flash——它的数据手册命令（Sector Erase / Page Program）背后就是本课的原理。

核心心智模型：保持电荷 vs 困住电荷

前两课的单元存储原理都是"保持电荷"——需要电源维持：

存储单元电荷状态如何保持
SRAM6T 锁存正反馈环路持续供电维持
DRAM1T1C电容存电荷，漏电需周期性刷新
Flash浮栅晶体管电荷被困在绝缘层包裹的浮栅里——无需电源，天然非易失

一句话：Flash 的区别不在"有没有电荷"，而在"电荷能不能逃逸"。

2. 一个变量解释一切：阈值电压 Vth

浮栅上有多少负电荷，直接决定晶体管的阈值电压 Vth（导通需要的栅压）。读数据时施加一个中间电压，看电流通不通：

状态浮栅电荷Vth读（施加中间栅压）逻辑值
擦除态无（少）电子低导通 → 有电流1
编程态电子被注入高截止 → 无电流0

多级单元（MLC/TLC）就是精细控制 多个 Vth 电平，一个单元存 2/3 bit——代价是各电平分布变窄、更易受干扰，需要更强的 ECC。

3. 三个操作：写 / 擦 / 读

⚡ 写 Program

控制栅加高压（15–20V），源/沟道接地 → Fowler-Nordheim 隧穿，电子穿过隧穿氧化层进入浮栅。

Vth 升高 → 0
🧽 擦 Erase

P 阱加高压 / 控制栅接地或负压 → 电场反向，电子被拉出浮栅。整块一起擦（块内所有字线）→ 全回 1。

Vth 降低 → 1
👁 读 Read

控制栅加中间电压（介于两种 Vth 之间），灵敏放大器检测有无电流。未选字线加 Vread≈4.5V 当"直通管"。

检测 Vth → 0/1

为什么"读快写慢"：读只测电压（ns 级）；写/擦要让电子穿过绝缘层（物理隧穿），需高压 + 时间（写 μs、擦 ms 级）。

⚠️ 三个反直觉但必须知道的特性
  1. 只能 1→0，不能 0→1。写入只是"加电荷"，把 1 变 0；要把 0 变回 1，只能靠整块擦除。→ 先擦后写（这是 SSD/FTL 最核心的约束）。
  2. 擦除以块为单位。一块内所有单元一起擦（字线共享），所以没有"改单个 bit"这回事，只能读-改-写整个页/块。
  3. 磨损有限。每次擦写都会轻微损伤隧穿氧化层，寿命受限：SLC ~10⁵ 次、MLC ~10⁴、TLC ~10³ 次/单元。→ SSD 需要磨损均衡（wear leveling）。

4. NAND vs NOR：结构决定命运

同一颗浮栅晶体管，连接方式不同就长出两种完全不同的产品：

NANDNOR
单元连接串联成串（像 NAND 门）并联（像 NOR 门）
密度高（~4F²，无需金属接触，可到 100×）低（~10F²，每单元独立接触）
访问粒度页（4–16KB）读/写，块擦除字节随机访问
读速度较慢（需页缓冲）快（50–100ns）
典型应用SSD / U盘 / 存储卡固件 / 启动代码（XIP 片上执行）
需要ECC + FTL（坏块管理、磨损均衡）相对少

你的板载 IS25L128F 是 NOR——所以它读快、支持随机读、适合放启动代码；而你的岗位主角 NAND 在 SSD 里以超高密度换顺序访问 + 强 ECC。

💡 一个打通全局的洞见

把三部曲放一起看：SRAM 用"电路状态"存、DRAM 用"电容电荷"存、Flash 用"困住的电荷"存。三者都是"有没有电荷 / 有多少电荷"的二元或多值编码——区别只在电荷如何进来、如何保持、如何读走。这个框架能帮你读任何存储数据手册。
