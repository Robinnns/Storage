存储器层次结构
为什么需要那么多种存储器？

🎯 本课目标

上完这课你能：画出存储器层次结构图，说出每种存储器在系统中的位置，并解释为什么不能用"一种最好的存储器"解决所有问题。

一个看似简单的问题

假设你在设计一台手机或一块SSD板卡。你需要存储数据——从CPU马上要用的指令，到用户拍的照片。你可能会想：为什么不直接用最大容量的存储器来干所有事？

答案藏在两个冷酷的物理事实里：

  1. 快的存储器一定小（物理距离 + 功耗限制）
  2. 大的存储器一定慢（地址线驱动 + 传感裕度）

这就是"存储墙"（Memory Wall）——CPU 速度增长远超内存速度增长，两者之间的鸿沟靠层次结构来弥合。

四种核心存储技术的本质区别

属性 SRAM DRAM NAND Flash NOR Flash
存储单元 6个晶体管（6T） 1个晶体管 + 1个电容（1T1C） 1个浮栅晶体管（1T） 1个浮栅晶体管（1T）
读取速度 0.5–2 ns 10–70 ns 20–100 μs 70–100 ns

核心洞察：每 bit 成本才是"上帝之手"

这张表回答了几个关键问题：

  1. 为什么不用 SRAM 做主存？太贵、太大、太耗电。每 bit 需要 6 个晶体管，容量做不大。
  2. 为什么不用 DRAM 做存储？断电就丢数据（易失），而且无法做到 NAND 的密度（4F² vs 6F²）。
  3. 为什么不用 NAND 做主存？太慢 — 读延迟是 DRAM 的 ~1000 倍，写延迟更离谱。而且只能写 ~10⁴ 次。
  4. 为什么 NOR 和 NAND 同时存在？NOR 读取快且支持按字节随机读（可以就地执行代码），NAND 密度更高适合存大量数据。
💡 系统集成视角的关键认知

在你今后的工作中，每当看到一个新的存储技术，问自己三个问题：

  1. 它落在层次结构的哪一层？（速度 / 容量 / 成本）
  2. 它是易失还是非易失的？
  3. 它的读写不对称性如何？（读快写慢？读慢写快？差不多？）

这三个问题能帮你迅速定位任何存储技术的角色和适用范围。
