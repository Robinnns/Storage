# plans/ — 规划与任务追踪

这个目录存放学习**规划**和**任务清单**，与 `projects/`（工程源码）和 `knowledges/`（知识点笔记）分离。

## 目录约定

| 文件 | 用途 |
|------|------|
| `roadmap.md` | **主学习路径**——分阶段计划，含任务勾选清单 |
| `roadmap-a7lite.md` | A7-LITE 开发板结合实践的学习计划（当前主线） |
| `session-log.md` | 每次学习会话的记录（做了什么、卡在哪、下次做什么） |

## 使用方式

- **勾选任务**：在 Markdown 预览或编辑器里点击 `[ ]` → `[x]`
- **更新进度**：每完成一个阶段，在对应文件里勾选，并在 `session-log.md` 追加一行
- **计划变更**：计划是活的，可以随时调整——但变更理由记录在 `session-log.md`

## 勾选清单语法

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
```

## 与工作区其他目录的关系

```
plans/        ← 你在哪（计划、任务、进度）
projects/     ← 你做过什么（工程、源码）
knowledges/   ← 你学到什么（知识笔记，双向链接）
lessons/      ← 结构化课程
reference/    ← 速查表
learning-records/ ← 学习里程碑记录
```
