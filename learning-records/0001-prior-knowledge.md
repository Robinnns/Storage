# Prior Knowledge: Digital/Systems EE Background

User has an EE/CE degree with a digital and systems focus. They are comfortable with:
- Digital logic design
- Computer architecture concepts (CPU, cache, memory hierarchy at a textbook level)
- System-level thinking

They are less comfortable with:
- Analog and mixed-signal circuits
- Device physics below the transistor operational level
- Real-world memory interface details (timing, signaling, protocols)

**Implications:** Lessons should leverage their computer architecture knowledge as an entry point, then build downward into hardware specifics. Don't start from device physics — start from system behavior and work inward.
