SRAM ≠ 寄存器：存储术语辨析

260731 · SRAMCache寄存器BRAMFPGA

1. SRAM vs CPU 寄存器

这是中文工程师中常见的混淆点。SRAM 不是寄存器。

属性CPU 寄存器SRAM Cache
位置CPU 数据通路内部CPU 旁边，独立阵列
寻址方式指令直接编码（如 R0, R1）通过内存地址访问
访问延迟0 周期（组合逻辑内）1–20 周期
物理实现触发器 (Flip-Flop) 或锁存器6T SRAM 单元阵列
数量几十～几百百万～亿级 bit
🔑 通俗类比
  • 寄存器 = 你手里正在写的草稿纸，低头就能看到
  • SRAM Cache = 桌上的文件夹，伸手够得到
  • DRAM = 身后的书架，需要站起来走过去

2. L1 / L2 / L3 Cache 的分工

三级 Cache 全部用 SRAM 制造，因容量和物理距离不同而天然形成层次：

层级容量延迟共享方式特点
L1 I-Cache32KB~0.5ns每核独享只存指令
L1 D-Cache32KB~0.5ns每核独享只存数据
L2256KB–1MB2–5ns每核或每簇指令+数据合并
L38–32MB5–20ns全芯片共享最后一道防线

3. BRAM（Block RAM）

BRAM 是 FPGA 领域的术语，指的是 FPGA 芯片内集成的专用 SRAM 硬核模块。

BRAM分布式 RAMDRAM
本质SRAM 硬核LUT 拼接的"伪 SRAM"1T1C DRAM
位置FPGA 片内FPGA 片内PCB 上（片外）
容量几十KB–几MB几KBGB 级
延迟1–2 周期1 周期几十ns + 控制器开销
需要刷新？否否是

一句话：BRAM 就是 FPGA 里的 SRAM 硬核。本质上和 CPU Cache 用同样的 6T SRAM 技术，只是封装形式不同。
