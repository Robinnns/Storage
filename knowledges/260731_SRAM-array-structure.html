SRAM 阵列结构详解

260731 · SRAM6T单元阵列结构灵敏放大器

全景框图

五层结构逐层拆解

第 1 层：6T 存储单元

六个晶体管分两组：

  • 4 个晶体管构成一对交叉耦合反相器（锁存器），两个稳定状态代表 0 和 1——这是"记忆"的物理本质
  • 2 个晶体管是访问管（Access Transistor），栅极接字线 WL，源漏连接位线 BL 和内部存储节点

平时访问管关闭（WL 低电平），存储节点悬空，但交叉耦合反相器的正反馈让状态保持稳定。读/写时 WL 拉高，访问管打开，存储节点才与外部位线连通。

第 2 层：字线 (Word Line)

同一根 WL 连接一整行所有单元（比如 1024 个）的访问管栅极。WL 拉高 → 整行单元的访问管同时打开 → 这一行所有 bit 同时暴露到各自的位线上。一次激活读出一整行。

选中哪一行？由 Row Decoder（行译码器） 根据地址高位决定：n 位地址 → 2ⁿ 根 WL 中选中 1 根。256 行 = 8 位行地址。

第 3 层：差分位线对 (BL / BL̅)

每一列有一对位线：BL（真）和 BL̅（互补）。这是 SRAM 设计的关键——差分信号。

🔑 为什么用差分？

6T 单元的两个存储节点 Q 和 Q̅ 天然互补（一个高电平另一个就一定低电平）。读操作时，Q 和 Q̅ 分别拉 BL 和 BL̅ 朝相反方向摆动——差分电压摆幅是单端的两倍，且对外部共模噪声天然免疫。灵敏放大器只需要判断"哪边更高"，不需要知道绝对值。

第 4 层：Column Mux（列多路选择器）

读出整行（比如 1024 bit）后，不需要全部输出——用 Column Decoder 根据地址低位，从 1024 列中选出 32 列（或 16/64 列，取决于 I/O 宽度），送给灵敏放大器。

这 32 路数据并行地被 Sense Amp 放大。

位线有巨大的寄生电容（几百 fF），而 6T 单元的驱动能力很弱。如果等位线电压自然稳定到满摆幅，需要 好几纳秒。灵敏放大器不等——位线刚拉开 ~50mV（五十分之一伏），它就果断判定 0 还是 1，瞬间拉到满摆幅数字电平。这个"提前判定"把读取延时从纳秒级压到了亚纳秒级。
