🔑 一句话核心

Xilinx 器件型号 = 从左到右逐级收敛的地址：前缀 → 系列 → 家族 → 规模 → 封装 → 速度 → 温度。读到「封装」这一级时，整个器件已经唯一确定了。

字段详解

字段含义说明
XCXilinx Commercial 前缀XC=商用；XA=汽车级；XD=防御级
7系列（工艺节点）7 系列 = 28nm。同系列共享工艺与架构
A家族定位A=Artix（低成本低功耗）· K=Kintex（中端平衡）· V=Virtex（高端最大）· Z=Zynq（带 ARM 的 SoC）
35T规模代号"35" 取整自 System Logic Cells ≈ 3.3 万；T 只是型号后缀。资源实测值见下
FGG484封装F=Flip-chip 倒装 · GG=无铅(RoHS) + 0.8mm 球间距 · 484=焊球数。板卡焊哪个封装就用哪个
-2速度等级-1 慢 → -2 中 → -3 快。影响最高可跑 Fmax，也影响价格
C温度等级C=商用 0~85℃ · I=工业 -40~100℃。丝印上常见

🧭 怎么确定板卡用的 part？
  1. 看芯片丝印（最权威）：FPGA 芯片正面印的一行字就是完整型号，如 XC7A35T-2FGG484C。
  2. 查原理图 + BOM：原理图里 FPGA 位号（通常 U1），对照 BOM 表的完整 part number。
  3. Vivado 里核对：新建工程 → 器件下拉搜 xc7a35t，对照丝印挑 FGG484 封装 + -2 速度。

⚠️ 注意格式转换：丝印 XC7A35T-2FGG484 → Vivado / TCL 里写成 xc7a35tfgg484-2（全小写、拼接、无空格）。
