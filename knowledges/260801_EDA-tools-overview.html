一、入门 / 学习级工具

图形化逻辑仿真

Logisim-evolution
开源 GPLv3
经典 Logisim 的活跃分支。拖放逻辑门+触发器+SoC 组件，实时看信号传播。支持 VHDL/Verilog 导出和 FPGA 板卡对接。最适合直观理解存储单元——搭 6T SRAM、D 触发器、小容量存储阵列。
Digital
开源 GPLv3 · HNeemann
Logisim-evolution 的竞品，UI 更现代、操作更流畅。同样支持 VHDL/Verilog 导出。功能不如 Logisim-evolution 多（无 SoC 组件），但作为逻辑仿真入门更轻量。

在线 HDL 仿真（免安装）

EDA Playground
免费在线 · edaplayground.com
浏览器写 Verilog/VHDL → 一键仿真 → 内置波形窗口。支持 Icarus、Verilator、VCS 等多种仿真引擎。芯片工程师的"JSFiddle"——面试或快速验证小模块时的首选。
WaveDrom
开源 · wavedrom.com
JSON 画时序图——不是仿真工具，是时序图绘制器。做笔记时画 DDR tRCD/tCL/tRP 时序关系，比手绘或 ASCII 图专业。可嵌入 Markdown 文档。

本地 HDL 仿真

Icarus Verilog (iverilog)
开源
Verilog-2005 的免费编译+仿真器。语法检查+仿真一体，输出 VCD 波形文件。大学数字设计的标准工具链：写 Verilog → iverilog 仿真 → GTKWave 看波形。
Verilator
开源
把 Verilog 编译成 C++ 再跑仿真——速度比 Icarus 快 10–100×，适合跑大规模回归。代价是 testbench 需用 C++ 写，上手门槛更高。学习阶段用 Icarus 就够了。
GHDL
开源
VHDL 版的 Icarus——如果你或你的团队用 VHDL 而非 Verilog。
GTKWave
开源
开源波形查看器，读取 VCD (Value Change Dump) 文件。通常和 Icarus Verilog 搭配：iverilog → .vcd → GTKWave。几乎每个 FPGA 教程第一课都是这套组合。

进阶开源工具

Yosys
开源
开源 RTL 综合器——Verilog → 门级网表。开源 FPGA 工具链的核心环节。
cocotb
开源
Python 写 testbench，底层调 Icarus/Verilator/GHDL——用 Python 的灵活性替代 Verilog testbench 的繁琐。验证效率提升一个数量级。

二、专业 ASIC 工具链

三大 EDA 厂商格局

Synopsys（新思）
全球第一
综合和时序领域统治级。VCS（仿真）、Design Compiler（综合）、PrimeTime（STA）、Verdi（调试）、SpyGlass（Lint）——几乎每个环节都有业界最好的工具。
Cadence（楷登）
全球第二
物理设计和验证强。Xcelium（仿真）、Genus（综合）、Innovus（布局布线）、JasperGold（形式验证）、Voltus（功耗分析）。
Siemens/Mentor（明导）
全球第三
DFT 和物理验证独大。Tessent（DFT 王者）、Calibre（DRC/LVS 物理验证，所有芯片流片前必跑）、QuestaSim（仿真）。

按设计流程排列

① Lint / 代码质量

SpyGlass
Synopsys
行业标准——Lint、CDC（跨时钟域检查）、RDC（复位域检查）一体。几乎没有芯片项目不用它。在仿真之前先扫一遍 RTL 代码质量。

② RTL 仿真

VCS
Synopsys
市场占有率最高的仿真器。编译速度快，SystemVerilog 全特性支持。亚洲芯片公司的黄金搭档：VCS + Verdi。国内 SSD 控制器、NAND 控制器团队大概率用这套。
Xcelium
Cadence
VCS 的竞品。并行仿真强，大规模回归时性能出色。配 SimVision 做波形调试。
QuestaSim
Siemens
FPGA 和 ASIC 通吃，界面友好。ModelSim 是其简化版（FPGA 圈子最普及）。

③ 综合 (Synthesis)

Design Compiler (DC)
Synopsys
ASIC 综合之王。RTL → 门级网表。台积电、三星所有工艺节点都支持。需要读 .lib/.db 标准单元库和 SDC 时序约束文件。
Vivado
AMD/Xilinx
FPGA 综合+布局布线一体。把 RTL 映射到 LUT+FF+BRAM+DSP。和 DC 本质不同——面向 FPGA 预置资源而非 ASIC 标准单元库。
Quartus
Intel/Altera
Intel FPGA 的综合+布局布线工具，Vivado 的竞品。

④ 静态时序分析 (STA)

PrimeTime (PT)
Synopsys
STA 的事实标准。不跑仿真，纯数学算出所有时序路径是否满足 setup/hold。流片前最后一道数字关卡。Foundry 签核（sign-off）只认它。
Tempus
Cadence
PrimeTime 的竞品。

⑤ 布局布线 (Place & Route)

Innovus
Cadence
物理设计市场份额第一。门级网表 → 标准单元放置 → 金属连线 → 时序/功耗优化。
IC Compiler II (ICC2)
Synopsys
Innovus 的竞品。

⑥ 调试 / 波形查看

Verdi
Synopsys
调试器之王。不只是看波形——自动追踪信号驱动源、画电路图、FSDB 波形分析和代码交叉索引。你在波形上看到一个 X（不定态），点一下就追溯到谁驱动的、哪个逻辑导致。国内存储控制器团队标配。
SimVision
Cadence
Xcelium 配套的波形+调试工具。
DVE
Synopsys
VCS 自带的调试器，Verdi 的简化版。

⑦ 形式验证 (Formal Verification)

Formality
Synopsys
数学证明综合后网表 ≈ 原始 RTL，不走仿真。用 SAT/BDD 算法。
JasperGold
Cadence
Cadence 的形式验证方案。也常用于属性检查（SVA 断言的穷举验证）。

⑧ DFT（可测试性设计）

Tessent
Siemens
DFT 工具链绝对王者。在芯片中插入扫描链（Scan Chain）、BIST 电路——量产时靠这些发现制造缺陷。几乎所有芯片的 DFT 都靠它。

⑨ 功耗分析

Voltus
Cadence
Cadence 的功耗签核工具。
RedHawk
Ansys（独立厂商）
IR-drop 和 EM（电迁移）分析的行业标准。

⑩ 物理验证（DRC / LVS）

Calibre
Siemens
物理验证的唯一王者。DRC（设计规则检查）和 LVS（版图 vs 原理图比对）。虽然不算"数字工具"，但所有芯片流片前必须跑 Calibre，没有例外。

💡 关键认知

对你来说最重要的两个工具是 VCS + Verdi——它们是日常主力。Verdi 的"反向追溯"能力（波形上点一个 X → 自动追踪到驱动源）是调试效率的核心。其余工具知道在整个流程中的位置和目的就够了——真正调 NAND 控制器时自然会深入。
