macOS 数字/逻辑电路绘图工具

260801 · 工具macOS电路图绘图

最推荐draw.io / diagrams.net
免费 · 原生 macOS 桌面版 + 网页 + VS Code
拖放式矢量绘图，零学习成本。导出 SVG/PNG/PDF 嵌入笔记。
  • 画门级电路、晶体管级电路、模块框图均胜任
  • 桌面版离线使用：github.com/jgraph/drawio-desktop
KiCad Eeschema
免费开源 · macOS / Win / Linux
PCB EDA 内置的原理图编辑器，有完整 MOS 管/逻辑门/无源器件符号库。画出来的图可直接放进技术文档。
  • 学习曲线比 draw.io 陡，但图更规范、符号更标准
Excalidraw
免费开源 · 网页版 + VS Code 插件
手绘风格，画草图极快。连线自动吸附。适合示意性框图、白板讨论。SVG 导出干净。
TikZ / CircuiTikZ (LaTeX)
免费开源 · 代码生成
学术论文/教科书画风。MOS 管、逻辑门全有现成宏。输出矢量 PDF。LaTeX 环境需自行搭建，学习曲线最陡。
SchemDraw (Python)
免费开源 · pip install
Python 画电路图，比 TikZ 简单。适合用代码批量生成。库不如 CircuiTikZ 全面。
